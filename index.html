    FAQ

    Questions from the undergrowth常见问题

    Who can mint?谁可以铸造？

    Only a Binance Agentic Wallet that holds a SPACE ID .ai Agent ID. The contract checks that the caller owns the Agent ID it mints with. Limits follow the Agent ID, so moving it to another wallet never resets them.只有持有 SPACE ID .ai Agent ID 的 Binance Agentic Wallet（币安 Agent 钱包）。合约会检查调用者是否拥有用于铸造的 Agent ID。额度跟随 Agent ID，转到其他钱包也不会重置。

    How many can one Agent ID mint?一个 Agent ID 能铸造多少个？

    1 free (either Free, or Invite-free through an inviter) and 5 paid at 0.003 BNB. Each other Agent ID it invites adds 1 paid mint, up to +5 (10 paid in total).1 个免费（普通免费，或通过邀请人的邀请免费）和 5 个付费（每个 0.003 BNB）。每邀请一个其他 Agent ID，增加 1 个付费额度，最多 +5（付费共 10 个）。

    What does the half-price mint need?半价铸造需要什么？

    An inviter’s tree id. The 0.0015 BNB price is available once per Agent ID, on the mint that first binds it to an inviter. After that, paid mints are 0.003 BNB.邀请人的树编号。每个 Agent ID 只有一次 0.0015 BNB 的价格，就是首次绑定邀请人的那次铸造。之后付费铸造均为 0.003 BNB。

    Why is there no “Connect wallet” button?为什么没有“连接钱包”按钮？

    Agent wallets sign through the agent, not a browser extension. A connect button would also be the first thing a phishing copy imitates. This site only reads public data. Prompts are on the Mint page.Agent 钱包通过 Agent 签名，而不是浏览器插件。而且“连接钱包”按钮正是钓鱼网站最先模仿的东西。本站只读取公开数据。提示词在铸造页面。

    What happens if paid doesn’t sell out?如果付费部分没有售罄会怎样？

    No token launches. Holders of paid trees refund 80% of their mint price; the tree is burned. Free trees stay as they are. See the refund guarantee.不发币。付费树持有者可退回铸造价格的 80%，该树会被销毁。免费树保持不变。详见退款保障。

    When is rarity known?什么时候知道稀有度？

    After the mint closes. The contract commits to a future block hash, then anyone calls reveal(). Until then every tree shows the same placeholder.铸造结束后。合约先锁定一个未来区块的哈希，然后任何人都可以调用 reveal() 开图。在此之前所有树都显示同一张占位图。

    When does the weekly burn happen?每周销毁什么时候执行？

    Automatically, whenever holders claim their airdrop or rewards and a weekly step is due. Anyone can also trigger it with burnScheduled(); it only costs gas.当某一周的销毁到期时，持有者领取空投或奖励会自动执行。任何人也可以调用 burnScheduled() 触发，只需支付 gas。

    How do I sell a tree?怎么出售一棵树？

    Send it to a regular wallet you control and list it on Element. Your Agent ID and mint quota stay with you. Step by step on the Sell page.把它转到你自己控制的普通钱包，然后在 Element 上架。你的 Agent ID 和铸造额度不会变。详细步骤见出售页面。

    What can the project owner still change?项目方还能修改什么？

    Before metadata is frozen: the image location and an optional stage module (art only). The owner cannot move mint funds, token buckets, prices, caps or royalties. After the final images are live, metadata is frozen and ownership is renounced.在元数据冻结之前：图片存放位置和一个可选的阶段模块（只影响图片）。项目方无法动用铸造资金、代币分配、价格、上限或版税。最终图片上线后，元数据冻结并放弃合约所有权。

    What are the 400 reserve trees?400 棵预留树是什么？

    Trees the project can mint (before close) for giveaways and partners. They earn like free trees (1× weight) and don’t add paid quota to anyone.项目方可以在铸造结束前铸造的树，用于赠送和合作方。它们的收益与免费树相同（1× 权重），也不会给任何人增加付费额度。
