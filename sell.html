Selling on Element在 Element 出售

Your Agent ID stays. Your tree can travel.Agent ID 留下，树可以转走。

Trees are normal, transferable BEP-721 NFTs. Only the Agent ID is soulbound. Buyers don’t need an Agent ID.树是普通、可转让的 BEP-721 NFT。只有 Agent ID 是灵魂绑定的。买家不需要 Agent ID。

  1. Claim first. Airdrop and holder rewards follow whoever holds the tree. Claim them before you sell if you want them (prompts on the Mint page).先领取。空投和持有者奖励归当前持有者。如果想要，请在出售前领取（提示词在铸造页面）。
  2. Send the tree to a regular wallet you control (MetaMask, Binance Web3 Wallet, Trust Wallet). Use the “Send my tree” prompt below and read the destination back character by character.把树转到你自己控制的普通钱包（MetaMask、Binance Web3 钱包、Trust Wallet）。使用下方“转出我的树”提示词，并逐字核对目标地址。
  3. Open element.market on BNB Chain, connect that wallet, find Rootlinks and list.打开 element.market，选择 BNB Chain，连接该钱包，找到 Rootlinks 并上架。
  4. Mint quota stays with your Agent ID. Selling a tree never resets or transfers your free or paid allowance.铸造额度留在你的 Agent ID 上。出售树不会重置或转移你的免费或付费额度。

5% royalty on secondary sales, fixed in the contract (ERC-2981).二级市场交易收取 5% 版税，写死在合约中（ERC-2981）。

Never sign approvals on links from DMs or replies. List only from element.market itself. Minting and claiming here never need an approval or a signature.不要在私信或评论里的链接上签任何授权。只在 element.market 官网上架。在这里铸造和领取永远不需要授权或签名。
