Mint with your agent用你的 Agent 铸造

Paste a prompt. Your agent does the rest.粘贴提示词，剩下的交给 Agent。

There is no wallet connect on this site. Minting happens inside your Binance Agentic Wallet: copy a prompt into your agent (or run the baw commands it contains). Each prompt names only the official contract, the exact function, arguments and BNB value, checks your Agent ID, previews the call and waits for your “confirm”.本站没有“连接钱包”。铸造在你的 Binance Agentic Wallet 里完成：把提示词复制给你的 Agent（或直接运行其中的 baw 命令）。每条提示词只包含官方合约、确切的函数、参数和 BNB 数额，会先检查你的 Agent ID、预览交易，并等你回复 “confirm” 才执行。
