# Credits

Every effect on this site is a from-scratch vanilla JS/CSS re-implementation. No component code was copied; the libraries below were studied for ideas only.

| Effect on this site | Where | Inspired by |
|---|---|---|
| Glowing root spine that draws itself as you scroll, with a light pulse travelling down and side roots lighting at each section | `js/effects.js` `rootSpine`, `.spine` CSS | Magic UI “Animated Beam” (https://magicui.design/docs/components/animated-beam), 21st.dev “Background Paths” (https://21st.dev) |
| Twinkling starfield with rare shooting stars + slow aurora glow in the sky | `starfield`, `.aurora` | React Bits “Galaxy”/“Aurora” backgrounds (https://reactbits.dev), Magic UI “Particles” |
| Animated number tickers on the live counters and burn tracker | `tick` | Magic UI “Number Ticker” |
| Gold sheen sweeping across “living trees” | `.shiny` | Magic UI “Animated Shiny Text”, React Bits “Shiny Text” |
| Light beam running around the border of the live mint card | `.beam-card .beam` | Magic UI “Border Beam” |
| Rarity cards with cursor spotlight, shared edge light and 3D tilt | `spotlight`, `groupSpotlight`, `.rcard` | React Bits “Spotlight Card” + “Tilted Card”, Magic UI “Magic Card”, 21st.dev “Spotlight Card” |
| Marquee of sample trees with soft edge fade, pauses on hover | `.marquee` | Magic UI “Marquee” |
| Dock navigation with magnification and active-section dot | `dock`, `.dock` | Magic UI “Dock” |
| Bento grid for the token split, with hover spotlight | `.bento` | Magic UI “Bento Grid”, React Bits “Magic Bento” |
| Terminal-style prompt viewer | `.term` | Magic UI “Terminal” |
| Copy button that morphs into a check | `.copy` | Uiverse.io copy buttons (https://uiverse.io, MIT) |
| Blur-fade reveal on scroll | `revealOnScroll` | Magic UI “Blur Fade” |
| Soil grain texture | `.soil` background | Magic UI “Noise Texture” |

Mobbin (https://mobbin.com) requires a login and was not used.
